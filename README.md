# Deep Digger (РудоКот) — APK releases and web version

A cozy mining game for Android: dig down through the mountain, sell ore, upgrade your gear and find the Heart of the Mountain. This repository holds **APK builds and the web build only**, no sources.

- **Play in the browser:** https://dmitryzemlyuk.github.io/deepdigger-releases/ (best in landscape; can be added to the home screen).
- **Install on Android:** download [the latest APK](https://github.com/DmitryZemlyuk/deepdigger-releases/releases/latest/download/DeepDigger.apk) and open it on the phone. Updates install over the previous version and keep the save (same signing key). Requires Android 8.0 or newer.
- Only the last 3 versions are kept; older releases and APKs are removed automatically.

Keyboard in the web version: arrows / WASD — move, climb and aim; Space — jump; J or X — dig; E or Enter — talk, shop, next line; 1–4 — ladder, dynamite, teleport, beacon; Esc — pause. Keys can be changed in Settings → Keyboard.
